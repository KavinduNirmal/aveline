# Reports

This folder contains all written reports for the SE3090 group assignment.

## Required documents

| File | Description |
|---|---|
| `group-report.md` | Consolidated group report covering system design, architecture, and implementation |
| `student1-individual-report.md` | Individual report for Student 1 (Customer Concierge & Memory) |
| `student2-individual-report.md` | Individual report for Student 2 (Visual Intelligence & Sourcing) |
| `student3-individual-report.md` | Individual report for Student 3 (Commerce Validation & Optimization) |

## Group report structure (suggested)

1. Project Overview
2. Architecture Overview (diagram required)
3. Technology Justification
4. Cross-platform workflow walkthrough (Flutter → API → Agent → DB → React → API → Flutter)
5. Testing strategy summary
6. Deployment summary
7. Challenges and lessons learned

## Individual report structure (suggested)

1. My slice: responsibilities and scope
2. Design decisions within my slice
3. Implementation highlights
4. Testing coverage for my slice
5. AI tool usage declaration
6. Reflection and improvements
