# What the Handbook Does Not Cover

This page exists so that a question with no answer gets an honest one. Everything below is
genuinely outside what has been written down so far. For any of it, ask the Aveline team rather
than assuming an answer.

## Refunds, cancellation and downgrades

There is no written refund policy, cancellation process or downgrade path. Plan changes, including
moving to a smaller plan, are arranged with the Aveline team, and the effective date is confirmed
with you before anything changes.

## Exporting or erasing data

There is no self-service export of your client book, and no self-service erasure. Removing a client
removes them from your boutique's view; a full export or a permanent erasure is handled by the
Aveline team on request. There is no published timeframe or format for either yet.

## What a single action costs in Blossoms

The handbook does not list the Blossom cost of individual actions such as composing a lookbook,
reading a garment from a photograph, or generating a reply. Blossoms are metered and shown per
period in Usage and Billing; a per-action price list is not published.

## Account lifecycle

Password or code recovery, two-factor recovery, changing your own name or email, closing a
boutique, and transferring ownership between people are not described here. Write to support and
the team will handle it.

## The API

API keys can be created, revoked and deleted in Settings, and plans carry API request limits. The
reference documentation for the API itself, including its base URL, authentication header, error
format and endpoint list, is not in this handbook.

## The mobile app

A mobile client exists alongside the web dashboard, but this handbook does not describe which
features differ between them or how to install it.

## Anything else that is not written here

If a question is not answered in the product documentation under `/docs` or in these company pages,
the honest answer is that the handbook does not cover it. Ask the Aveline team.
